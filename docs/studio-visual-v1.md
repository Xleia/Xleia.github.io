# Xleia Studio：夜间工作室交互视觉样板 V1

日期：2026-11-18（Asia/Tokyo）。独立开发路径：`/studio/visual/`。

## 原因与验收口径

用户对照 V0.8 截图和已选定的夜间工作室设计稿，明确指出实装的视觉差距过大，要求先做出接近设计稿效果的一版。

V0.7 的 8/8 功能验收和三档 60.0 rAF FPS 不构成正式 3D 美术验收。V0.8 的 CI 成功同样不能证明构图、模型、材质、灯光达到参考。当前低多边形 WebGL 场景仍作为技术预览保留。

本轮交付是**固定视角的高保真交互视觉样板**：一张按用户设计稿生成的完整房间场景，加真实可用的热点、二维局部放大、返回、项目面板和站内导航。图像缩放不产生真实三维视差；没有新增可自由环绕的精细模型或实时全局光照，不能宣称正式 3D 已完成。

## 视觉目标

- 人眼高度正面构图，以主显示器和蓝色城市夜景为中心。
- 左侧整面书架具有密集书本、植物、摆件和层间暖光。
- 胡桃木桌面与地板、网背办公椅、织物地毯具有可读的细节。
- 右侧实验台、软木便签板、暖色壁灯与布艺休息区。
- 默认界面轻量，让画面先成立，再通过热点展示项目信息。

## 文件与行为

- `public/studio/visual/index.html`：无需外部 JavaScript 库的页面、样式及交互。
- `public/studio/visual/room.webp`：1672 × 941 场景底图，392,614 字节。由本次生成的 PNG 进行 WebP 编码，用于网页交付。
- `src/pages/studio/index.astro`：原技术预览新增清晰的视觉样板入口。
- 5 个区域沿用 `src/data/studio.ts` 的项目语义和站内目标：KOTO、Train Libre 中文版、Blog、Tech Lab、About / Now。
- 手机端显示完整场景及可点击导航；减少动态偏好下取消过渡。
- 不加载外部字体、CDN 或遥测，不在静止状态运行持续渲染循环。

## 验证

Astro 检查、静态构建和 29 个页面的路由及链接检查已通过。在模拟 1440 和 390 像素宽度的 DOM 中，已验证五个热点与底部入口、项目链接、Escape 返回及 2D 导航开关。桌面与手机浏览器的实际排版、点击区域和视觉还原度待实机确认。

## 后续真实 3D 的工作

以这次确认的正面主机位作为统一对照，建立对应的真实家具、房间、植物与道具模型；制作一致比例的 PBR 材质；用烘焙间接光、接触阴影和少量动态光完成暖冷层次。之后在同一机位截取实际 WebGL 画面做视觉比较，再恢复有限范围的镜头移动并测量性能。

生成图像不会自动变成可旋转模型。后续资产制作、烘焙、WebGL 集成以及目标设备性能测试均为独立未完成工作。

## 图像来源与生成说明

由用户本轮提供的《Xleia Studio｜3D 夜间工作室设计稿 V1.0》作为视觉参考，使用内置图像生成工具制作；不复用当前低模截图作为最终美术。未使用 CLI / API 密钥。

生成提示的关键约束：参考设计稿第 2 节正面空间构图与第 3 节默认相机；单张连续室内画面，无界面、无拼贴；中央胡桃木工作台与 KOTO 显示器，左侧书架，右侧实验台、沙发和圆桌；深蓝东京风格城市夜景、暖色实际灯具、细致木纹和布料、柔和接触阴影；人眼高度广角建筑摄影；禁止等距模型盒子和低模玩具外观。
