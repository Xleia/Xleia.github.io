# Xleia Studio V0.3 — 模型、材质与夜间灯光优化

## 本次实现

在 V0.2 **已通过 8/8 项本地浏览器验收**的原生 WebGL2 场景上优化视觉细节；沿用第一张夜间私人工作室设计稿与原始五个热点空间位置。不引入新依赖，不修改生产分支或网站正式首页。

- 家具建模：增加圆柱台灯罩、椭球软装/绿植、杯具、显示器音箱、耳机、抽屉、柜门拉手等非纯立方体元素
- 主桌面：增加胡桃木边沿、抽屉、黄铜细节、纸张、显示器标记和 KOTO 波形细节
- 书架：书脊标签、横放书籍与植物，保留 Blog 热点
- Lab：电路板、机箱、设备指示灯、发光芯体
- Train Libre：手机示意界面增加状态、柱状图与菜单线条，不使用未经授权的真实私有项目截图
- About：沙发靠垫、绿植与留言板
- Shader 材质响应：木纹微扰、金属高光、布艺纹理和屏幕/灯罩的不同粗糙度
- 灯光：暖色台灯、主屏/实验台冷色光，添加局部简化接触阴影（并非物理精确投影阴影）

## 验收

打开本地 `/studio/`，确认：

1. 原生 WebGL2 3D 场景正确显示，并能看到增强的椭球软装、台灯罩、书架与物件细节
2. 胡桃木桌面、金属与布艺在深夜灯光下能辨认材质差异，光照不过度曝光
3. KOTO、Train Libre、Blog、Lab、About 五个热点正常
4. 点击聚焦、拖动、缩放、Escape、重置与返回均正常
5. 2D 模式、窄屏回退和 WebGL 不支持设备的站内导航正常
6. 正式首页、项目详情、19 篇文章及原永久 URL 未受影响
7. `npm.cmd run check` / `npm.cmd run build` / `npm.cmd run verify:site` 成功

## 交付和限制

- 这是使用程序化低多边形 Mesh 的 WebGL2 V0.3，不是照片级模型、GLB 资产或真正的 PBR + shadow-map 渲染。
- 不引入 Three.js npm 依赖；如果后续希望贴近第一张参考图，应独立评估 Blender/GLB、PBR 纹理、光源阴影与资源加载预算。
- CI 只能证明静态检查与构建通过，真实浏览器 GPU 视觉和交互必须由本地 Chrome/Edge 验收。
- `gh-pages` 和原站备份保持不变；正式上线属于后续 P5。
