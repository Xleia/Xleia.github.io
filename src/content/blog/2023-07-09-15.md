# SpringBoot3-数据访问

## 整合SSM场景

SpringBoot整合Spring、SpringMVC、Mybatis 进行<b>数据访问场景开发</b>

### 1、创建SSM整合项目

在pom文件中导入坐标

```xml
<dependency>
    <groupId>org.mybatis.spring.boot</groupId>
    <artifactId>mybatis-spring-boot-starter</artifactId>
    <version>3.0.2</version>
</dependency>

<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```

### 2、配置数据源

```javascript
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.datasource.type=com.zaxxer.hikari.HikariDataSource
spring.datasource.url=jdbc:mysql://localhost:3306/db1
spring.datasource.username=root
spring.datasource.password=123456
```

安装MybatisX插件，能够自动帮我们创建myabtis的xml文件

### 3、配置Mybatis

在启动类添加注解，扫描mybatis接口

```java
@MapperScan(basePackages = "com.huang.mapper")
@SpringBootApplication
public class Boot305SsmApplication {

    public static void main(String[] args) {
        SpringApplication.run(Boot305SsmApplication.class, args);
    }

}
```

在配置文件编写，扫描mybatis的xml文件

```javascript
# 配置整合mybatis
mybatis.mapper-locations=classpath:/mapper/*.xml
#开启驼峰命名
mybatis.configuration.map-underscore-to-camel-case=true
```

### 4、CRUD编写

[UserMapper.java](http://UserMapper.java)类

```java
public interface UserMapper {

    User getUserById(@Param("id") Long id);

}
```

UserMapper.xml

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd" >
<mapper namespace="com.huang.mapper.UserMapper">
    <select id="getUserById" resultType="com.huang.entity.User">
        select id,username,password,chineseName
        from test_admin
        where id=#{id};
    </select>
</mapper>
```

jdbc场景的几个自动配置

```javascript
# 数据源的自动配置;所有与数据源有关的配置都在 spring.datasource;默认使用HikariDataSource
org.springframework.boot.autoconfigure.jdbc.DataSourceAutoConfiguration
# 给容器中放了jdbcTemplate操作数据库（用来做数据库操作的，不过一般不用，因为有了专门的Mybatis框架）
org.springframework.boot.autoconfigure.jdbc.JdbcTemplateAutoConfiguration
# 
org.springframework.boot.autoconfigure.jdbc.JndiDataSourceAutoConfiguration
# 做分布式事务的；基于XA二阶提交协议的分布式事务数据源
org.springframework.boot.autoconfigure.jdbc.XADataSourceAutoConfiguration
# 支持事务
org.springframework.boot.autoconfigure.jdbc.DataSourceTransactionManagerAutoConfiguration
```
