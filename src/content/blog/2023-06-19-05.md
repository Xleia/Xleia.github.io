## indexOf()与lastIndexOf()区别

<b>直接上代码</b>

```java
//indexOf()与lastIndexOf()的区别
public static void main(String[] args) {
String s1 = "123456789";
String s2 = "888000888";
String s3 = "123456778";
System.out.println(s1.indexOf("8"));//7
System.out.println(s1.lastIndexOf("8"));//7

System.out.println(s1.indexOf("0"));//-1
System.out.println(s1.lastIndexOf("0"));//-1

System.out.println(s2.indexOf("8"));//0
System.out.println(s2.lastIndexOf("8"));//8

System.out.println(s3.indexOf("7"));//6
System.out.println(s3.lastIndexOf("7"));//7
}
```

得出结论！！

- <code>indexOf()</code>是从左往右查询，如果查到则返回该字符在字符串中的索引（都是从0开始）
- <code>lastIndexOf()</code>是从右往左查询，如果查到则返回该字符在字符串中的索引（都是从0开始）
- 如果没查到都是返回-1
