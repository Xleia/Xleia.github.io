\*\*报错：\*\*Cannot convert value of type ‘com.github.pagehelper.PageHelper’ to required type ‘org.apache.ibatis.plugin.Interceptor’ for property ‘plugins\[0\]’: no matching editors or conversion strategy found

## 问题描述：sqlSessionFactory初始化失败

修改前的applicationContext-dao.xml配置：

```xml
<bean id="sqlSessionFactory" class="org.mybatis.spring.SqlSessionFactoryBean">
        <property name="dataSource" ref="dataSource"/>
        <property name="typeAliasesPackage" value="com.huang.pojo"/>
        <property name="plugins">
            <array>
                <bean class="com.github.pagehelper.PageHelper"> <!--此时这里报错-->
                    <property name="properties">
                        <value>helperDialect=mysql</value>
                    </property>
                </bean>
            </array>
        </property>
        <property name="configLocation" value="classpath:sqlMapConfig.xml"/>
    </bean>
```

## 原因分析：

通过查阅[官网](https://pagehelper.github.io/docs/)得知，因为上面的相关PageHelper配置是4.x版本的，老版的拦截器<code>Interceptor</code>和分页插件实现类<code>dialect</code>都是在<code>com.github.pagehelper.PageHelper</code>这个类下，但是5.x版本的<code>PageHelper</code>只是<code>dialect</code>的实现类，而新版的拦截器则是在<code>com.github.pagehelper.PageInterceptor</code>下，所以需要配置<code>PageInterceptor</code>。

pageHelper是如何在[mybatis](https://so.csdn.net/so/search?q=mybatis&spm=1001.2101.3001.7020)中工作呢，是通过mybatis的pulgin实现了Interceptor接口，从而获得要执行的sql语句实现分页技术。

## 解决方案：

修改后的applicationContext-dao.xml配置：

```xml
<bean id="sqlSessionFactory" class="org.mybatis.spring.SqlSessionFactoryBean">
        <property name="dataSource" ref="dataSource"/>
        <property name="typeAliasesPackage" value="com.huang.pojo"/>
        <property name="plugins">
            <array>
                <bean class="com.github.pagehelper.PageInterceptor">
                    <property name="properties">
                        <value>helperDialect=mysql</value>
                    </property>
                </bean>
            </array>
        </property>
        <property name="configLocation" value="classpath:sqlMapConfig.xml"/>
    </bean>
```

修改后成功运行。
